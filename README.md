# Statistical Genetics · 统计遗传学

A searchable statistical genetics concept dictionary with definitions, equations, assumptions, and method comparisons.

**Website:** [Statistical Genetics](https://nemo-bio.github.io/Statistical-Genetics/)

- [中文（中英文对照）](https://nemo-bio.github.io/Statistical-Genetics/?lang=zh)
- [English](https://nemo-bio.github.io/Statistical-Genetics/?lang=en)

The dictionary contains 92 concepts across six modules and 66 groups of equations. It includes module navigation, six entries per page, cross-module search, priority filters, adjustable text size, and a terminology self-test.

## Files and publishing

`index.html` is the complete website. Styles, scripts, equations, fonts, and both language versions are embedded, so the downloaded file also works offline. Module navigation and pagination switch views in the browser; all entries are bundled in this one file.

GitHub Pages publishes from the root of the `main` branch. To update the website, replace `index.html` and push to `main`. The `.nojekyll` file keeps the prebuilt website from being processed by Jekyll.

Original papers and software documentation are linked in the dictionary's Sources section.
